---
title: "Install the on-premise agent"
description: "Install the aiGust agent on a server, for bookkeeping software that runs at your firm instead of in the cloud."
---

When your bookkeeping software runs on a server at your firm, aiGust can't reach it over the internet. A small program, the agent, then sends the data from your server to aiGust.

Two connectors need the agent: [Adsolut](/setup/data/bookkeeping/adsolut) and [Expert/M](/setup/data/bookkeeping/expert-m). All other connectors connect from aiGust to your software over the internet.

## Install the agent

When you add a connector that needs the agent, the last step is **Download & install the agent**.

1. Click **Download agent**.
2. Install it on a server that always has access to the database of your bookkeeping software.
3. Schedule the agent to run, for example every night. The server needs to be on at that time.
4. Follow the instructions that come with the agent.

There's no activation step: the connector works once the agent runs.

This part of the documentation is for key users: the colleagues with the **Office key user** role, who set up aiGust for the whole firm. See [Roles and permissions](/setup/users/roles).

Here you learn how to:

- set up and manage [data connectors](/setup/data/overview)
- add and manage [users](/setup/users/manage-users), and decide which administrations they see
- set up the branding of [the aiGust portal](/setup/branding/portal) and [the emails](/setup/branding/email-templates)
- tailor aiGust for your colleagues: [meeting flows](/configure/meetings/meeting-flows), [triggers](/configure/triggers/built-in-triggers) and [report settings](/configure/reporting/report-view-defaults)
- [report a problem to us](/setup/support/report-a-bug): only key users can create tickets

Looking for how to use aiGust with your clients? Go to the [User guide](/guide/getting-started/log-in).

## Where to start

Follow the [onboarding checklist](/setup/onboarding-checklist). It takes you through the setup in the right order, starting with the connectors: without data, there's not much you can do in aiGust.

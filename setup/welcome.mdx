This guide is for the key users of your firm: the people who set up aiGust for everyone, and keep it running.

The documentation has three parts:

- **[Welcome](/):** what aiGust is, in a nutshell.
- **Key user guide,** this part: everything you set up for your whole firm, such as the connectors, branding, users and meeting flows.
- **[User guide](/guide/getting-started/log-in):** how accountants work with aiGust every day.

## What a key user is

Key user is a role in aiGust: **Office key user**. Only key users can set up aiGust for the whole firm. See [Roles and permissions](/setup/users/roles).

Most key users also work with aiGust every day, as accountants. At some firms, a key user is an IT administrator who doesn't use aiGust otherwise.

Key users:

- set up and manage the [connectors](/setup/data/overview), so aiGust gets the data of your clients;
- add the [users](/setup/users/manage-users) of your firm, and decide which administrations they see;
- set up the [branding](/setup/branding/portal) and the [emails](/setup/branding/email-templates);
- set up everything your colleagues then use, such as the [meeting flows](/configure/meetings/meeting-flows), [triggers](/configure/triggers/built-in-triggers) and [report settings](/configure/reporting/report-view-defaults).

There's no limit on the number of key users. Most firms have between two and ten.

### The first point of contact

Key users know aiGust best, and are in direct contact with us. When colleagues have a question or run into a problem, they go to a key user first. If the key user can't solve it, they [report it to us](/setup/support/report-a-bug): only key users can create tickets.

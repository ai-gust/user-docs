aiGust gives you two complementary tools for understanding how your workspace is being used: a **Usage overview** that shows high-level platform activity at a glance, and an **Audit trail** that records every meaningful action taken by every user. Together, they help you manage capacity, satisfy compliance requirements, and investigate any unexpected changes to data or settings.

<Note>
  Both the usage overview and the audit trail are accessible only to users with the **Admin** role.
</Note>

## The usage overview

The usage overview is a live dashboard summarising key activity metrics across your entire workspace.

### Accessing the usage overview

Go to **Settings → Usage & Audit Trail** and click the **Overview** tab.

### What the overview shows

<CardGroup cols={3}>
  <Card title="Active users" icon="users">
    The number of team members who have logged in at least once during the selected time range.
  </Card>
  <Card title="Active administrations" icon="folder-open">
    How many client administrations have had at least one action (import, report, meeting) during the period.
  </Card>
  <Card title="Data syncs" icon="arrows-rotate">
    The total number of data imports or integrations syncs completed in the period.
  </Card>
  <Card title="Reports generated" icon="chart-line">
    The count of reports produced, broken down by report type.
  </Card>
  <Card title="Meeting records created" icon="calendar-check">
    The number of structured meeting agendas or summaries saved in the workspace.
  </Card>
  <Card title="External access invitations" icon="user-plus">
    How many client portal invitations were issued during the period.
  </Card>
</CardGroup>

Use the **date range selector** in the top-right of the overview to change the reporting window. Available presets are last 7 days, last 30 days, last 90 days, and a custom date range.

<Tip>
  Export the usage summary as a CSV for a monthly snapshot to include in internal management reports. Click **Export overview** in the top-right corner of the Overview tab.
</Tip>

## The audit trail

The audit trail is an immutable, time-stamped log of user actions across your workspace. It cannot be edited or deleted by anyone, including Admins.

### Accessing the audit trail

Go to **Settings → Usage & Audit Trail** and click the **Audit trail** tab.

### What events are logged

Every significant action in aiGust generates an audit log entry. Logged events include:

<Accordion title="Authentication events">
  - Successful login (user, timestamp, IP address, device)
  - Failed login attempts
  - Password reset requests
  - Session terminations (sign-out or automatic timeout)
</Accordion>

<Accordion title="User management events">
  - User invited, activated, deactivated, and removed
  - Role changes (who changed which user's role, and from which role to which)
  - Administration access granted or revoked for a user
</Accordion>

<Accordion title="Data import and sync events">
  - File upload initiated and completed (file name, uploader, administration)
  - Integration sync triggered and completed (source system, administration)
  - Import errors or failures (with error code)
</Accordion>

<Accordion title="Report and export events">
  - Report generated (report type, administration, generating user)
  - Report exported to PDF (report name, exporting user, timestamp)
  - Report shared with an external user
  - Report deleted
</Accordion>

<Accordion title="Meeting events">
  - Meeting agenda created or updated
  - Meeting agenda sent to a client
  - Action items added, updated, or marked complete
</Accordion>

<Accordion title="Settings and configuration events">
  - Firm details updated
  - Branding or email template changed
  - Subscription plan changed
  - Administration created, archived, or deleted
</Accordion>

### Each log entry contains

| Field | Description |
|---|---|
| **Timestamp** | Date and time of the event, in your workspace time zone |
| **User** | Full name and email of the user who performed the action |
| **Event type** | The category and specific action (e.g. *Report → Exported to PDF*) |
| **Target** | The object the action was performed on (e.g. administration name, report title, user email) |
| **IP address** | The IP from which the action was taken |
| **Detail** | Any additional context recorded for the event |

## Filtering the audit log

Use filters to narrow a large log down to the entries that matter.

<Steps>
  <Step title="Open the filter panel">
    On the **Audit trail** tab, click **Filter** to expand the filter panel above the log table.
  </Step>

  <Step title="Apply your filters">
    You can combine any of the following filters:

    - **Date range** — enter a from and to date, or choose a preset.
    - **User** — select one or more users from the dropdown to see only their actions.
    - **Event category** — select from Authentication, User management, Data import, Reports, Meetings, or Settings.
    - **Administration** — limit results to actions taken within a specific client administration.
    - **IP address** — enter a specific IP to investigate activity from a single location.
  </Step>

  <Step title="Apply and review">
    Click **Apply filters**. The log table updates to show only matching entries. The active filter count is shown on the Filter button so you always know if a filter is in place.
  </Step>

  <Step title="Clear filters">
    Click **Clear all filters** to return to the full unfiltered log.
  </Step>
</Steps>

## Exporting the audit log

<Steps>
  <Step title="Filter the log if required">
    Apply any filters to narrow the export to the relevant date range, user, or event category before exporting.
  </Step>

  <Step title="Click Export log">
    Click **Export log** in the top-right corner of the **Audit trail** tab.
  </Step>

  <Step title="Choose a format">
    Select **CSV** for spreadsheet analysis or **PDF** for a formatted printable record. Then click **Download**.
  </Step>
</Steps>

The exported file includes all columns visible in the audit trail table. CSV exports can be imported directly into Excel or Google Sheets for further filtering and analysis.

<Warning>
  Audit log exports may contain personal data such as user names, email addresses, and IP addresses. Handle exported files in accordance with your firm's data protection policy and applicable privacy regulations (e.g. GDPR).
</Warning>

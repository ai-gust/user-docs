Connecting Yuki to aiGust gives you a live feed of your client bookkeeping data — chart of accounts, journal transactions, and period balances — synced automatically so your reports are always up to date. The integration uses a Yuki API token that you generate once and enter in aiGust. No ongoing manual steps are required after the initial setup.

<Note>
  **Before you begin, confirm you have the following:**
  - An active Yuki account with access to the administrations you want to sync
  - The **Domain administrator** role in Yuki, which is required to generate an API token
  - An aiGust account with the **Firm Admin** role
</Note>

## Setting Up the Connection

<Steps>
  <Step title="Generate an API token in Yuki">
    Log in to your Yuki portal and go to **Settings → API**. Click **Generate new token**. Give the token a descriptive name such as `aiGust integration` so you can identify it later. Copy the token immediately — Yuki only shows the full token value once.

    <Warning>
      Store the API token securely before leaving the Yuki settings page. If you navigate away without copying it, you will need to revoke the token and generate a new one.
    </Warning>
  </Step>

  <Step title="Open the Connectors page in aiGust">
    Log in to aiGust and go to **Settings → Connectors**. Click **Add connector** and select **Yuki** from the list of available integrations.
  </Step>

  <Step title="Enter your Yuki domain and API token">
    In the Yuki connector form, enter:
    - **Yuki domain** — your Yuki domain name (for example, `yourfirm.yuki.nl`)
    - **API token** — the token you generated in the previous step

    Click **Verify credentials**. aiGust contacts the Yuki API to confirm the token is valid and the domain is reachable. A green checkmark confirms a successful connection.
  </Step>

  <Step title="Select administrations to sync">
    After credentials are verified, aiGust loads the list of Yuki administrations available under the connected account. Toggle on each administration you want to sync. For each one, choose or create the corresponding administration in aiGust using the dropdown on the right.

    <Tip>
      If you manage a large number of Yuki administrations, use the search box at the top of the list to find specific clients quickly.
    </Tip>
  </Step>

  <Step title="Start the initial sync">
    Click **Save and sync**. aiGust begins the initial full sync for each selected administration. The status indicator changes to **Syncing**. Depending on the volume of historical transactions, the first sync may take several minutes per administration.
  </Step>
</Steps>

## Verifying the Sync

Once the initial sync finishes, the status for each administration changes to **Up to date**. To confirm everything has come through correctly:

1. Open an administration in aiGust and go to **Financial data → Chart of accounts**. Check that the account codes and descriptions match what you see in Yuki for that administration.
2. Go to **Financial data → Transactions** and verify that recent bookkeeping entries appear with the correct dates, amounts, and account codes.
3. If any data appears missing, open **Settings → Connectors**, select the Yuki connector, and review the sync log for warnings or errors.

<Tip>
  aiGust syncs Yuki data automatically every four hours. To pull in the latest changes right away — for example, after a client's accountant finishes a posting batch — click **Sync now** next to the administration in **Settings → Connectors**.
</Tip>

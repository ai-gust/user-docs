Connecting Odoo to aiGust lets you pull chart of accounts data, journal entries, and account balances directly from your Odoo instance. Whether you run Odoo Online, Odoo.sh, or a self-hosted Odoo server, the setup process is the same: enter your instance URL and API credentials, then map each Odoo company to an administration in aiGust.

<Note>
  **Before you begin, confirm you have the following:**
  - The URL of your Odoo instance (for example, `https://yourcompany.odoo.com` or your self-hosted address)
  - An Odoo user account with the **Accountant** or **Advisor** access rights under the Accounting module, across all companies you want to sync
  - An Odoo API key (recommended) or the username and password for the Odoo account
  - An aiGust account with the **Firm Admin** role
</Note>

## Setting Up the Connection

<Steps>
  <Step title="Generate an API key in Odoo">
    In Odoo, click your user avatar in the top-right corner and select **My Profile**. Under the **Account Security** tab, click **New API Key**. Give the key a name such as `aiGust` and confirm. Copy the key immediately — Odoo only displays it once.

    <Warning>
      API keys are tied to the Odoo user account that creates them. If that user account is deactivated or loses accounting access rights, the aiGust sync will fail. Use a dedicated service account for this integration if your Odoo setup supports it.
    </Warning>
  </Step>

  <Step title="Open the Connectors page in aiGust">
    Log in to aiGust and go to **Settings → Connectors**. Click **Add connector** and select **Odoo** from the list of available integrations.
  </Step>

  <Step title="Enter your Odoo connection details">
    Fill in the Odoo connector form with the following details:
    - **Odoo URL** — the full URL of your Odoo instance, without a trailing slash
    - **Database name** — the name of the Odoo database (visible on the Odoo login screen if you have multiple databases)
    - **Username** — the login email of the Odoo user account
    - **API key** — the key you generated in the previous step (or the account password if you are not using an API key)

    Click **Verify connection**. aiGust contacts your Odoo instance to confirm the credentials are valid and that the account has the required accounting permissions.
  </Step>

  <Step title="Map Odoo companies to aiGust administrations">
    After the connection is verified, aiGust loads the list of companies available in your Odoo instance. For each Odoo company you want to sync, select or create the corresponding administration in aiGust using the dropdown on the right.

    <Tip>
      In a multi-company Odoo setup, each company has its own chart of accounts and journal entries. Map each company individually to keep client data separate in aiGust.
    </Tip>
  </Step>

  <Step title="Start the initial sync">
    Click **Save and sync**. aiGust begins the initial full sync for each mapped company. The status indicator changes to **Syncing**. The first sync fetches the complete chart of accounts and full transaction history, so it may take a few minutes per company.
  </Step>
</Steps>

## Verifying the Connection

When the initial sync completes, the status changes to **Up to date** with a timestamp. To verify the data:

1. Open a mapped administration in aiGust and go to **Financial data → Chart of accounts**. Confirm that the account codes and names correspond to those in the relevant Odoo company.
2. Go to **Financial data → Transactions** and check that journal entries appear with the correct dates, amounts, and account references.
3. If data looks incomplete, open **Settings → Connectors**, select the Odoo connector, and review the sync log for any errors or access warnings.

<Tip>
  Self-hosted Odoo instances must be reachable over the public internet for aiGust to sync data. If your Odoo server is behind a firewall or VPN, work with your IT team to whitelist aiGust's IP addresses. Contact aiGust support for the current list of egress IPs.
</Tip>

Connecting Silverfin to aiGust lets you bring structured financial data from your Silverfin client files directly into aiGust's reporting and analysis environment. The connection uses OAuth, so you authorise aiGust through your Silverfin account without sharing passwords. Once connected, aiGust syncs chart of accounts data, period balances, and transaction details from your selected client files on an automatic schedule.

<Note>
  **Before you begin, confirm you have the following:**
  - An active Silverfin account with access to the client files you want to sync
  - The **Partner** or **Administrator** role in Silverfin — standard user roles may not have sufficient API access
  - An aiGust account with the **Firm Admin** role
</Note>

## Setting Up the Connection

<Steps>
  <Step title="Open the Connectors page in aiGust">
    Log in to aiGust and go to **Settings → Connectors**. Click **Add connector** and select **Silverfin** from the list of available integrations.
  </Step>

  <Step title="Initiate the OAuth authorisation">
    Click **Connect with Silverfin**. aiGust redirects you to the Silverfin login page. Sign in with the Silverfin account that has access to the client files you want to sync.
  </Step>

  <Step title="Authorise aiGust in Silverfin">
    After signing in, Silverfin displays a permissions screen showing what aiGust is requesting access to. aiGust requests read-only access to your firm's client file data, including chart of accounts, period balances, and transactions. Click **Authorise** to grant access and return to aiGust.

    <Warning>
      You must authorise with a Silverfin account that has **Partner** or **Administrator** level access. Authorising with a restricted user account may result in only a partial list of client files being available for sync selection.
    </Warning>
  </Step>

  <Step title="Select client files to sync">
    After authorisation, aiGust loads the list of Silverfin client files available in your firm's workspace. Toggle on each client file you want to sync. For each file, select or create the matching administration in aiGust using the dropdown on the right.

    <Tip>
      Use the search box to find specific clients quickly if your Silverfin workspace contains a large number of client files.
    </Tip>
  </Step>

  <Step title="Start the initial sync">
    Click **Save and sync**. aiGust begins the initial full sync for each selected client file. The status indicator changes to **Syncing**. The first sync pulls the complete chart of accounts and all available period data, which may take a few minutes per client file.
  </Step>
</Steps>

## Verifying the Connection

Once the initial sync completes, the status for each client file changes to **Up to date** with a timestamp. To confirm the data is correct:

1. Open an administration in aiGust and go to **Financial data → Chart of accounts**. Check that account codes and names correspond to those in the Silverfin client file.
2. Go to **Financial data → Transactions** and verify that period entries appear with the correct dates and amounts.
3. If any data is missing or incorrect, navigate to **Settings → Connectors**, select the Silverfin connector, and review the sync log for warnings.

<Tip>
  aiGust syncs Silverfin data automatically every four hours. To pull in the latest Silverfin data immediately before a client meeting or report run, go to **Settings → Connectors** and click **Sync now** next to the relevant administration.
</Tip>

This guide is for everyone who wants to integrate with aiGust — software vendors connecting their product, integration partners exchanging data, and developers building against the aiGust API.

## Ways to integrate

### API integration

Need to read data out of aiGust, or embed an aiGust functionality in your own product? Contact us at [support@ai-gust.io](mailto:support@ai-gust.io) to discuss the possibilities.

### External data uploads

Want to integrate by providing data ? Contact us at [integrations@ai-gust.io](mailto:integrations@ai-gust.io).

This integration path is fully documented in this guide:

- [Upload data as an integration partner](/integrate/overview) — the concept and the lifecycle
- [Upload files through the API](/integrate/upload-api) — a step-by-step walkthrough
- [Reference](/integrate/reference) — endpoints, error codes and file conventions
